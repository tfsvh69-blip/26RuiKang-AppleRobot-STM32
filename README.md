# 26RuiKang 苹果采摘机器人 · STM32 控制端

> **当前版本：V4.1**（2026-06-23 优化）
> 本版本实现了机器人半圈运行路径的控制逻辑整合与初步调试，整体框架运行正常，部分运动参数仍需进一步调优。

---

## 项目简介

本项目为苹果采摘机器人的 STM32 下位机控制程序，基于 **STM32F4** 系列主控，运行 **FreeRTOS** 实时操作系统。机器人通过激光雷达进行场地导航，配合搭载 RealSense 深度相机的树莓派完成苹果视觉检测，由机械臂和末端执行器完成抓取、剪切与投放动作。

## 通信协议概要

STM32 与树莓派通过串口通信，协议流程如下：

| 指令 | 发送方 | 含义 |
|------|--------|------|
| `PING` | STM32 | 确认树莓派协议就绪 |
| `WATCH` | STM32 | 开始持续识别苹果 |
| `WATCH_STOP` | STM32 | 停止持续识别 |
| `HIT` | 树莓派 | 检测到苹果，通知停车 |
| `SCAN` | STM32 | 请求重新取帧并返回抓取坐标 |
| `FRUIT` | 树莓派 | 返回苹果三维坐标 |
| `NONE` | 树莓派 | 当前帧无有效目标 |

详细协议说明见 [COMMUNICATION_PROTOCOL.md](COMMUNICATION_PROTOCOL.md)。
